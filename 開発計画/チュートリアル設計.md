# チュートリアルモード設計案

## モードの流れ

メインメニュー「チュートリアル」→ 固定手順の対戦 → 同じ盤面からフリーバトル

- 双方のデッキと山札順を固定し、シャッフルしない。
- 相手の行動も順番に定義する。
- 手順終了後は操作制限を解除し、相手を通常AIに切り替える。
- HP・マナ・盤面・手札・山札・ターンなどの対戦状態は引き継ぐ。

## 1つの手順に説明・矢印・操作をまとめる

**説明文と矢印を表示している間、指定された操作だけを受け付ける。**
説明を読んで「次へ」を押してから操作する構成にはしない。
指定操作が成功し、戦闘などの解決が終わったら次の手順へ進む。

| 項目 | 内容 |
| --- | --- |
| `id` | 手順の識別子 |
| `actor` | プレイヤー／相手 |
| `message` | 操作と同時に表示する説明文 |
| `target` | 矢印で示すカードやボタン |
| `action` | プレイヤーに許可する操作、または相手が実行する固定行動 |

相手の手順でも説明と矢印を表示し、定義された行動を自動実行する。

## 手順の例

| 説明文 | 矢印 | 許可する操作 |
| --- | --- | --- |
| 手札の山賊を選ぼう | 手札の山賊 | そのカードの選択 |
| 山賊を配置しよう | 指定位置の＋ | その位置への配置 |
| 攻撃してみよう | 山賊のグループの攻撃ボタン | そのグループの攻撃 |

カード選択と配置は別の操作なので手順を分けるが、各手順の説明・矢印・操作は同時に出す。
選択したカードは次の配置手順まで保持する。

## 実装方針

- 台本は「固定デッキ」「カードの別名」「手順配列」で管理する。
- 同名カードを区別するため、別名を開始時のデッキ位置からカード1枚に対応付ける。
- 誘導先はカードや配置位置の意味で指定し、固定の画面座標にはしない。
- 通常のゲーム処理と対戦画面を共有し、表示と入力処理の両方で操作を制限する。
- 攻撃後の自動ターン交代を含め、通常のルールに従って進行する。
- 手順中は通常AIを止め、相手の固定行動だけを実行する。
- 手順の最後で誘導を外し、対戦を作り直さず自由操作へ移る。

具体的なデッキ・手順・文章・終了後のAI難易度は次に決める。
