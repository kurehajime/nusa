# Easyの連続召喚先読みを無効化

Easyだけ、各メイン行動の直後を既存の`evaluateBattleEntry`で評価する。Normal・Hardは既存の召喚ロールアウトを続ける。Easyの手札2枚除外、攻撃プレビュー、相手盤面の攻撃脅威評価は維持する。行動後は再判断するので、実際には複数枚の召喚も可能。

## 固定条件での比較

2026-09-27実施。変更直前のソースを退避し、変更後と比較。相手はHard、拡張なし。6デッキの異なる全組み合わせについて各先後10シード、さらにEasy側を交代し、各版600戦。各Easyデッキ100戦、先後50戦ずつ。

- 山札：既存`createRoundRobinSchedule`、seed 20260816、gamesPerSide 10。各デッキのshuffle saltを使う既存のFisher–Yatesシャッフル。
- 手札除外：既存大会と同じ乱数アルゴリズムを使い、seedは対戦seed XOR `0x517ce` XOR（EasyがAなら1、Bなら2）。各試合で初期化。行動が変わった後は手札内容も変わるため、同じカードが除外される保証はない。
- 打ち切り：200ターンまたは10,000行動。未決着は両版0戦。

Easyのメイン判断1回の平均時間は0.568ms→0.174ms（約69%短縮）。各版を順に実行し、`chooseAction`のメインフェイズ呼び出しだけを計測。行動後の局面・呼び出し回数も変わるため、同一局面の厳密な速度比較ではなく、ローカル対戦中の実測値。

Hard相手の固定シード標本では、複雑な追加ルールなしにEasyを弱くできた。人間相手の勝率を示す数値ではない。Normal・Hardの選択処理は変更していないため、既存のHard同士の勝率JSONは更新していない。

## 局面・自動検証

マナ4、相手に山賊、召喚可能手札が荒くれ者・暗殺者・投石機の局面を追加。除外対象は先頭のコスト5カードとし、全難易度で召喚可能な候補を揃える。Easyは投石機、Normal・Hardは荒くれ者から暗殺者へ連続召喚する。全難易度が勝ちにつながる攻撃を選ぶことも確認。

`npm test`：240件成功。`npm run lint`、`npm run build`：成功。

ローカルブラウザーでもフリーバトルのEasyで暗殺者を配置して手番を渡し、COMがゴリラを召喚・攻撃してプレイヤーへ手番が戻ることを確認した。
