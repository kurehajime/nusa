# 拡張カードの平均勝率上昇値

通常ログと全拡張カードの2枚追加ログを最新の同じルール・AI・デッキ構成で揃えた後、`npm run ai:export-expansion-gains` を実行する。
対戦は再実行せず、ログの勝敗数から `src/game/ai/deck-expansion-win-rate-gains.json` を一括更新する。
カードの性能やAIを変更した場合は、先に通常・拡張の検証を再実行すること。ログだけでは実装の一致を自動判定できない。

```ts
import gains from './ai/deck-expansion-win-rate-gains.json'

const gain = gains[deckId][expansionCardId]
```

- キーはデッキUUID → 拡張カードUUID。
- 値は「拡張カード2枚追加時の勝率 − 通常時の勝率」。0.05は5パーセントポイント上昇。低下も負数で保持する。
- 他の5デッキと先後を均等に対戦した平均。通常は各デッキ300戦、拡張は追加側として各デッキ150戦。対戦相手側は通常デッキ。
- 丸め前の勝敗数から差を計算し、小数点以下4桁に丸める。個々の対戦を同一シードで対応付けた因果効果ではなく、保存済み検証の平均勝率差。
- ログ欠落、集計重複、所定戦数の不足、未決着、シード・ターン上限の不一致はエラーにしてJSONを上書きしない。
- 4枚追加や複数種類を併用した際の効果は表さない。シナリオのHard・Very Hardでは、この値の順位からCOMへ追加する拡張カードを選ぶ。
